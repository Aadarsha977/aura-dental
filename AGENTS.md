# AGENTS.md

## Project Context

This is the web application repository for Aura Dental & Implant Suite. It is built with standard React 18, Vite, Tailwind CSS, Lucide Icons, and Framer Motion.

## Key Files & Directories

- `src/`: frontend application source code.
- `src/components/aura/`: clinic-specific landing page sections and widgets.
- `src/components/ui/`: reusable UI primitives (radix-based dialogs, inputs, buttons).
- `src/pages/`: top-level page components (Home, Login, Register, ForgotPassword, ResetPassword).
- `public/`: static assets including local clinic images and icons.
- `vite.config.js`: standard Vite build configuration.

## Development Workflow

- Run `npm run dev` to start the local Vite development server.
- Run `npm run build` to verify production builds.
- Run `npm run lint` to execute code quality checks.
